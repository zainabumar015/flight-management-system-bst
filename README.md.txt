# Flight Management System

## Project Description
This is a C++ project that manages flight records using a Binary Search Tree (BST). Each flight is stored using a unique Flight ID.

## Features
- Add a new flight.
- Search for a flight by ID.
- Delete a flight.
- Display all flights.
- Search flights by destination.
- Calculate flight duration and ETA.
- Save and load flight records using file handling.

## Technologies Used
- C++
- Binary Search Tree (BST)
- File Handling

## How to Run
1. Open the project in Visual Studio.
2. Build the project.
3. Run the program.
4. Select an option from the menu.
